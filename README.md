# Melodia
Registrar,buscar melodias


Nos dimos a la tarea de crear un tipo de biblioteca de melodias la cual registra,nombres,id,compositor,Anio de creacion y muchas mas opciones 

Opcion 1: Registra la melodia 
solicita al usuario,el nombre de la melodia,el cantante,compositor,Genero,el formato,el anio,y precio en ese orden

Opcion 2:Muestra el catalogo,Solo necesitas seleccionar esa opcion y aparecen todas las melodias registradas.

Opcion 3: Borrar melodia,solo necesitas poner el id y se borrara.

Opcion 4 : Muestra el valor total de la biblioteca de melodias

Opcion 5 : Muestra de menor a mayor precio 

Opcion 6 : pemite actualizar por id si es que cuando la registraste cometiste un error

Opcion 7 : Muetra las canciones desde la mas antigua a la mas nueva 

Opcion 8 : Muestra los nombres de las melodias en orden 

Opcion 9 : Permite buscar la melodia por año

Opcion 10 : Busca y muestra el compositor que solicitaste .

Opcion 11: Muestra los generos de las melodias registradas.

Opcion 12 :Permite buscar la cancion por el cantante 

Opcion 13 :Muestra los cantantes registrados.

Opcion 14:Muestra la cantidad de formatos que tiene cada melodia 

y el ultimo es Salir osea la opcion 15.
